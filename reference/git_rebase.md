# `git rebase` — Command Reference

> Reapply commits on top of another base tip

## Overview
The `git rebase` command is an essential tool in enterprise Git pipelines and source code management.

### Usage
```bash
git rebase --help
```

- Atomic commit discipline
- Automated peer-review and CI/CD validation
- Co-authored pair engineering standards
