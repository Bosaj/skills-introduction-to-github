# `git diff` — Command Reference

> Show changes between commits, commit and working tree

## Overview
The `git diff` command is a fundamental component of professional Git and version control engineering.

### Usage
```bash
git diff --help
```

### Best Practices
- Keep history atomic and clean.
- Enforce peer reviews and branch protections.
- Automate continuous integration with GitHub Actions.
