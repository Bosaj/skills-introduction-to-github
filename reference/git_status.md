# `git status` — Command Reference

> Show the working tree status, staged and unstaged files

## Overview
The `git status` command is a fundamental component of professional Git and version control engineering.

### Usage
```bash
git status --help
```

### Best Practices
- Keep history atomic and clean.
- Enforce peer reviews and branch protections.
- Automate continuous integration with GitHub Actions.
